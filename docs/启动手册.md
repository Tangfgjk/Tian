# 天机学堂 — 本地启动手册

## 📋 环境要求

| 依赖 | 版本/说明 |
|------|----------|
| JDK | 11（或 17，需切换到 jdk17 分支） |
| Maven | 3.6+ |
| Docker Desktop | 最新版，用于运行中间件容器 |
| IDEA | IntelliJ IDEA（推荐） |
| Node.js | 17.8.0（前端模块需要） |
| 操作系统 | Windows 10+ / macOS / Linux |

**建议内存**：开发机 ≥ 16GB，中途按需启动微服务，不要一次性全开。

---

## 🐳 第一步：启动 Docker 中间件

### 1.1 确认 Docker 运行

打开 Docker Desktop，确保右下角状态为 **Running**。

### 1.2 检查配置文件

进入 `docker-local/` 目录，确认 `.env` 文件存在且内容正确：

| 变量 | 说明 | 当前值 |
|------|------|--------|
| `MYSQL_PORT` | MySQL 端口 | `13306` |
| `MYSQL_ROOT_PASSWORD` | MySQL root 密码 | `541521` |
| `REDIS_PORT` | Redis 端口 | `16379` |
| `REDIS_PASSWORD` | Redis 密码 | `541521` |
| `RABBITMQ_USER` | RabbitMQ 用户名 | `root` |
| `RABBITMQ_PASSWORD` | RabbitMQ 密码 | `541521` |
| `RABBITMQ_VHOST` | RabbitMQ 虚拟主机 | `/tjxt` |

### 1.3 启动容器

打开 PowerShell，执行：

```powershell
cd docker-local

# 启动所有中间件
.\start-infra.ps1

# 检查服务状态
.\check-infra.ps1
```

### 1.4 验证各服务

| 服务 | 地址 | 说明 |
|------|------|------|
| Nacos 控制台 | http://127.0.0.1:8848/nacos/ | 配置中心/注册中心 |
| RabbitMQ 管理 | http://127.0.0.1:15672/ | 消息队列管理界面 |

## 🗄️ 第二步：导入数据库

```powershell
cd docker-local

# 导入业务数据库（会创建 14 个 tj_ 开头的库）
.\import-sql-fixed-v2.ps1

# 出现提示时输入：IMPORT
```

导入后会在 MySQL 中创建以下数据库：

```
tj_auth   tj_course   tj_data    tj_exam     tj_learning
tj_media  tj_message  tj_pay     tj_promotion tj_remark
tj_search tj_trade    tj_user    tj_chat
```

---

## ⚙️ 第三步：导入 Nacos 配置

```powershell
cd docker-local

# 将 nacos/DEFAULT_GROUP/ 下的配置导入 Nacos
.\import-nacos.ps1
```

完成后打开 http://127.0.0.1:8848/nacos/ → **配置管理** → **配置列表**，确认 18 个配置文件已导入，同时确认 **命名空间** 中存在 `tianji-local`。

---

## 🔧 第四步：IDEA 配置

在 IDEA 中打开项目根目录 `online-mooc`，等待 Maven 依赖下载完成。

### 4.1 环境变量

每个需要启动的微服务都必须配置 Environment Variables。在 IDEA 的 Run Configuration 中添加：

```
SPRING_PROFILES_ACTIVE=local
SPRING_CLOUD_NACOS_SERVER_ADDR=127.0.0.1:8848
SPRING_CLOUD_NACOS_DISCOVERY_IP=127.0.0.1
TJ_JDBC_HOST=127.0.0.1
TJ_JDBC_PORT=13306
TJ_JDBC_USERNAME=root
TJ_JDBC_PASSWORD=541521
TJ_REDIS_HOST=127.0.0.1
TJ_REDIS_PORT=16379
TJ_REDIS_PASSWORD=541521
TJ_MQ_HOST=127.0.0.1
TJ_MQ_PORT=5672
TJ_MQ_USERNAME=root
TJ_MQ_PASSWORD=541521
TJ_MQ_VHOST=/tjxt
```

> 💡 **技巧**：可以在 IDEA 的 `Edit Configurations` → 左上角新建一个 **Compound** 或使用 **EnvFile** 插件统一管理，避免每个服务重复粘贴。

### 4.2 编译项目

```bash
mvn clean compile -DskipTests
```

确保没有编译错误。

## 🚀 第五步：启动微服务

### 启动顺序

按照依赖关系，建议按以下顺序启动：

| 优先级 | 模块 | 主类 | 必启动 |
|--------|------|------|--------|
| ★1 | `tj-gateway` | `GatewayApplication` | ✅ |
| ★2 | `tj-auth/tj-auth-service` | `AuthApplication` | ✅ |
| ★3 | `tj-user` | `UserApplication` | ✅ |
| 4 | `tj-course` | `CourseApplication` | 按需 |
| 5 | `tj-learning` | `LearningApplication` | 按需 |
| 6 | `tj-trade` | `TradeApplication` | 按需 |
| 7 | `tj-pay/tj-pay-service` | `PayApplication` | 按需 |
| 8 | `tj-promotion` | `PromotionApplication` | 按需 |
| 9 | `tj-media` | `MediaApplication` | 按需 |
| 10 | `tj-remark` | `RemarkApplication` | 按需 |
| 11 | `tj-search` | `SearchApplication` | 按需 |
| 12 | `tj-message/tj-message-service` | `MessageApplication` | 按需 |
| 13 | `tj-exam` | `ExamApplication` | 按需 |
| 14 | `tj-chat` | `ChatApplication` | 按需 |
| 15 | `tj-data` | `DataCenterApplication` | 按需 |
| 16 | `tj-live` | `LiveApplication` | 按需 |

> 带 ★ 的 **最少必启动**，其余可选择性启动。

### IDEA 启动步骤

1. 打开对应模块下的 `*Application.java`
2. 右键 → **Run 'XxxApplication'**
3. 观察控制台日志，出现 `Application 'xxx' is running!` 即启动成功
4. 在 Nacos 控制台 `服务管理 → 服务列表` 中可见该服务实例

## ❗ 常见问题

### 1. 启动报错 `Connection refused` 连 MySQL

> 检查 `TJ_JDBC_PORT` 是否为 `13306`（不是默认的 `3306`）

### 2. 启动报错 `无法连接 Nacos`

> 确保 Nacos 容器正常运行：`docker ps | grep nacos`
> 检查环境变量 `SPRING_CLOUD_NACOS_SERVER_ADDR=127.0.0.1:8848`

### 3. Redis 连接失败

> 检查环境变量 `TJ_REDIS_PORT=16379`（不是默认的 `6379`）

### 4. 部分服务启动但报中间件连接失败（ES / MongoDB / MinIO）

> 这是正常的。Docker Compose 只部署了核心中间件，非核心中间件缺失不会阻塞服务启动，只影响对应功能。

### 5. IDEA 内存不足

> 在 `Help → Edit Custom VM Options` 中调大 IDEA 堆内存，例如 `-Xmx4096m`

### 6. Docker 容器占满磁盘

> 定期清理：`docker system prune -a`（注意会删除未使用的镜像和卷）
