## 📝 配置结构说明

项目配置采用**三层覆盖**机制：

```
代码默认值（application.yml）
    ↓ 被覆盖
Nacos 配置中心（shared-*.yaml）
    ↓ 被覆盖
环境变量（IDEA Run Configuration 或系统环境变量）
```

Nacos 中的占位符 `${tj.jdbc.password:123}` 含义：优先读环境变量 `tj.jdbc.password`，未设置时用默认值 `123`。本机开发时应通过环境变量注入真实值，**不要修改 Nacos 中的默认值提交到仓库**。
