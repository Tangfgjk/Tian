## 🧩 后端微服务模块

### 基础设施层

| 目录 | 类型 | 定位 | 内部结构 |
|------|------|------|----------|
| `tj-common/` | 公共包 | 所有模块共用的工具类、注解、自动配置 | `autoconfigure/`（Redisson锁、MQ、MyBatis、Swagger、XXL-JOB）、`constants/`、`domain/`、`enums/`、`exceptions/`、`utils/` |
| `tj-api/` | 接口包 | 跨服务调用的 Feign Client 接口定义、DTO | `client/`（各服务调用接口）、`dto/`（传输对象） |
| `tj-gateway/` | 网关 | Spring Cloud Gateway 全局路由、鉴权过滤 | `filter/`（`AccountAuthFilter` 鉴权、`LogTrackingFilter` 日志）、`config/`、`swagger/` |
| `tj-auth/` | 认证中心 | 多模块聚合，认证授权完整实现 | 见下方拆解 |

**`tj-auth/` 内部拆解（DDD 分层微服务示例）**：

| 子模块 | 定位 |
|--------|------|
| `tj-auth-common/` | 认证相关的通用类、JWT 常量 |
| `tj-auth-gateway-sdk/` | 网关专用鉴权 SDK（`AuthUtil`） |
| `tj-auth-resource-sdk/` | 微服务专用鉴权 SDK |
| `tj-auth-service/` | 认证服务本体（登录、授权实现） |

### 业务服务层

| 目录 | 定位 | 典型内部结构 |
|------|------|-------------|
| `tj-user/` | 用户中心 | 用户 CRUD、角色管理 |
| `tj-course/` | 课程中心 | 课程/目录/分类/教师管理 |
| `tj-learning/` | 学习中心 | `controller/`、`service/`、`domain/dto/`、`domain/po/`、`mapper/` |
| `tj-trade/` | 交易中心 | 购物车、订单、退款、**Spring 状态机**（`OrderStateMachineConfig`） |
| `tj-pay/` | 支付中心 | 多模块聚合（`tj-pay-api` / `tj-pay-domain` / `tj-pay-service`），支付宝/微信对接 |
| `tj-promotion/` | 营销中心 | 优惠券 CRUD、Lua 脚本秒杀、组合优惠推荐算法 |
| `tj-media/` | 媒资管理 | MinIO 文件上传、腾讯云 VOD 视频管理 |
| `tj-remark/` | 互动中心 | 点赞系统（Redis 缓存 + 定时持久化） |
| `tj-search/` | 搜索服务 | Elasticsearch 课程检索、用户画像推荐 |
| `tj-message/` | 消息中心 | 多模块聚合：私信/群聊 WebSocket、系统通知、短信平台 |
| `tj-exam/` | 考试中心 | 考试管理、成绩记录 |
| `tj-live/` | 直播中心 | 直播推流 |
| `tj-chat/` | AI 服务中心 | LangChain4j 对话、Qdrant 向量知识库 RAG、SSE 流式输出 |
| `tj-data/` | 数据中心 | InfluxDB 日志埋点、数据大屏、协同过滤推荐算法 |

> **多模块聚合**的模块（`tj-auth`、`tj-pay`、`tj-message`）具有 `-api`、`-domain`、`-service` 三层拆分，标准 DDD 分层：
> - `*-api`：对外暴露的接口和 DTO
> - `*-domain`：领域模型
> - `*-service`：业务实现 + Spring Boot 启动类

### 典型模块内部结构

以 `tj-course/` 为例，所有单体业务模块结构一致：

```
tj-course/
├── pom.xml
└── src/main/java/com/tianji/course/
    ├── CourseApplication.java    # Spring Boot 启动入口
    ├── config/                   # 线程池、本地缓存等配置
    ├── constants/                # 模块常量、Redis Key 前缀、错误信息
    ├── controller/               # REST 控制器
    ├── domain/
    │   ├── dto/                  # 入参对象
    │   ├── po/                   # 持久化对象（数据库映射）
    │   ├── query/                # 分页查询对象
    │   └── vo/                   # 出参对象
    ├── enums/                    # 枚举
    ├── mapper/                   # MyBatis-Plus Mapper
    └── service/
        ├── IXxxService.java      # 服务接口
        └── impl/
            └── XxxServiceImpl.java  # 服务实现
```

## 📄 根目录文件

| 文件 | 用途 | 是否可修改 |
|------|------|-----------|
| `pom.xml` | Maven 父 POM，管理所有模块和依赖版本 | ⚠️ 谨慎修改 |
| `Dockerfile` | 通用 Docker 镜像构建模板，各微服务共用 | ⚠️ 谨慎修改 |

| `README.md` | 项目主页说明 | 可增补 |
| `LICENSE` | Apache 2.0 开源协议 | ❌ 不需要改 |
| `天机学堂-扩展.md` | 项目改造详细笔记 | 可增补 |
| `.gitignore` | Git 忽略规则 | 可增补 |
